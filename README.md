# Friendship Jar Spell — Vintage Gothic Version

A fictional early-2000s gothic screen-prop website inspired by personal homepages, fan sites, and web-ring layouts.

## Open the website

Open `index.html` in Chrome, Safari, or Firefox. No installation is required.

## Add your images

Open the `images` folder and read `README.txt`. Add your images using the exact filenames listed there. Each on-page placeholder disappears automatically when its matching image exists.

## Main files

- `index.html` — page structure and wording
- `style.css` — vintage gothic design and mobile layout
- `script.js` — image replacement, material checklist, menu notices, and guestbook interaction
- `images/README.txt` — image filenames and recommended sizes

## Disclosure

This fictional website was created as a screen prop. It is not intended to provide factual spiritual, medical, or professional guidance. Some text and design development used generative AI assistance.
